Jak je DataDesk postavený Technologie, data a postup

Technologie: HTML, CSS a JavaScript v prohlížeči; stejný pravidlový modul běží také z Node.js CLI. Import XLSX používá místní SheetJS 0.20.3 v pracovním procesu. Žádná externí API ani AI.

Postup: CSV nebo XLSX se načte místně, zachovají se původní řádky, kontrolují se formáty a nejednoznačné duplicity, pak se spárují objednávky s expedicí. Částky se počítají v haléřích a měny se neslučují.

Výstup: nálezy s odkazy na zdroj, poznámky k prověření a CSV/JSON export. Ukázka používá fiktivní data; poznámka neopravuje zdrojový soubor.

DETAIL NÁLEZU

Nová kontrola

Porovnejte dva exporty. Názvy jejich sloupců můžete před kontrolou přiřadit. Pro portfolio používejte fiktivní data.

Začněte vzorovými soubory

Stáhněte CSV, upravte několik hodnot a nahrajte oba soubory zpět.

UTF-8 · čárka, středník nebo tabulátor · nejvýše 2 MB a 20 000 řádků na soubor. Soubory se zpracují v prohlížeči a nikam se neodesílají. XLSX: vyberete list a řádek hlavičky; sešity se vzorci, makry nebo externími odkazy se odmítnou. Rozbalený obsah nejvýše 32 MB.

Export výsledků

Přehled nálezů a úplný protokol zahrnují vše. Filtrovaný CSV obsahuje aktuální výběr ze stránky Nalezené problémy, napříč všemi stránkami. Seznam úkolů obsahuje jen dosud neprověřené nálezy.

Prověření nálezu neznamená opravu zdrojových dat. Tento rozdíl je zachovaný i v exportu.

Od dat k rozhodnutí

DataDesk porovnává export objednávek s exportem expedice. Všechny přehledy se počítají při spuštění z aktuálních dat.

  1. Zvolte scénář. Vyzkoušejte chybný, čistý nebo větší export.
  2. Projděte nálezy. U každého najdete důvod i původní záznamy.
  3. Zaznamenejte prověření. Přidejte poznámku; původní data zůstanou beze změny.
  4. Exportujte výsledek. CSV pro práci v tabulce, JSON pro úplný protokol.

Žádná AI ani placené API. Kontroly jsou pravidlové. Poznámky ukázkových scénářů se mohou ukládat do tohoto prohlížeče; nejde o sdílený firemní audit.
